## 🌌 Overview & Features

- **Cinematic Hero Video Player:** 16:9 responsive display with backdrop ambient glow, interactive playback controls (seek, volume, fullscreen), track progress, and seamless auto-advance.
- **Strict HTTPS Media Delivery:** 100% of all video streams, audio, and cosmic assets are enforced and delivered securely over HTTPS via Cloudflare R2 storage.
- **Shorts Dimension:** 9:16 vertical reels player for rapid frequency transmissions, fully synchronized with the main broadcast player.
- **21-Track Curated Cosmic Archive:** Rich metadata, categories (`Holy & Good`, `Gemini Music`, `Goalogique Live Set`, `Cosmic Rhythm`, `Ritual Dance`, `Goa Spirit`, etc.), view statistics, and 15+ mature rating badges.
- **Category Filter & Dynamic Grid:** Instant category switching and responsive 4-column card grid with live active track indicators.
- **Cosmic Transmission Feed:** Real-time user transmission comments with localStorage persistence and instant broadcasting.
- **Ecosystem & Partner Hub:** Direct alliances and sovereign network routing for Google Partnerships, xAI Grok Labs, and Meta Culture Network.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/HolybookoofgoodOrg/tv2-holybookofgood.git
cd tv2-holybookofgood
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
